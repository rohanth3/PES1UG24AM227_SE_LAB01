# Static Code Analysis Issues — Movie Theater Ticket Booking System

This document catalogs genuine code quality, style, and security issues detected in `ticket_booking_system.py` using **Pylint**, **Bandit**, **Flake8**, and manual code inspection.

## Identified Issues Table

| Issue | Type | Line(s) | Description | Fix Approach |
|---|---|---|---|---|
| Unsafe Shell Command Execution (Command Injection) | Security (Bandit B605 / CWE-78) | 58 | `os.system("echo Seating chart exported to: " + filename)` executes a command through the system shell using unvalidated string concatenation. If `filename` contains shell metacharacters, arbitrary shell commands can be injected and executed. | Remove `os.system` and the subshell completely. Use Python's standard `print()` statement for terminal notifications, or use `subprocess.run()` with `shell=False` if external process execution is required. |
| Insecure Expression Evaluation (`eval`) | Security (Bandit B307 / CWE-78, CWE-95) | 42 | `eval(promo_expr)` dynamically evaluates arbitrary Python code passed as a string. An untrusted promo expression can execute arbitrary system commands, access files, or import malicious modules (Remote Code Execution). | Avoid dynamic code execution. Replace `eval` with a safe discount calculation function (such as parsing structured discount parameters or a safe numeric discount percentage) that avoids arbitrary expression execution. |
| Weak Cryptographic Hash Function (`MD5`) | Security (Bandit B324 / CWE-327) | 47 | `hashlib.md5(ticket_code.encode()).hexdigest()` uses MD5, which is cryptographically broken and vulnerable to collision and preimage attacks. Using it for ticket verification hashes undermines integrity. | Upgrade the hashing algorithm to a modern secure cryptographic standard, such as SHA-256 (`hashlib.sha256(ticket_code.encode()).hexdigest()`). |
| Insecure Pseudo-Random Number Generator for Security PIN | Security (Bandit B311 / CWE-330) | 51 | `random.randint(1000, 9999)` relies on the Mersenne Twister PRNG from the standard `random` module, which is predictable and unsuitable for security-sensitive tokens and PINs. | Use the cryptographically secure `secrets` module (e.g., `secrets.SystemRandom().randint(1000, 9999)` or `secrets.randbelow()`) to generate unpredictable PINs. |
| Mutable Default Argument | Bug / Logic (Pylint W0102) | 15 | `order_history=[]` defines a mutable list as a default argument. In Python, default arguments are instantiated once when the function is defined, causing state to leak and accumulate across multiple calls that omit the parameter. | Use `order_history=None` as the default argument, and initialize a new list inside the function body (`if order_history is None: order_history = []`). |
| Bare Exception Handler with Silent Suppression | Bug / Reliability (Pylint W0702, Bandit B110 / CWE-703, Flake8 E722) | 26-27 | `except: pass` catches all exceptions indiscriminately (including `KeyboardInterrupt` and `SystemExit`) and silently swallows them, masking bugs and preventing clean debugging. | Replace the bare `except:` with explicit exception handling (catching `KeyError` for dictionary lookups), or log/report errors appropriately instead of silently ignoring all exceptions. |
| Unmanaged File Resource Handling | Quality / Resource Management (Pylint R1732, W1514) | 55-57 | `f = open(filename, "w")` opens a file without a context manager and without specifying text encoding. If an error occurs before `f.close()`, the file descriptor leaks. Missing encoding also causes platform-dependent issues. | Use a `with open(filename, "w", encoding="utf-8") as file:` context manager to ensure guaranteed closure and deterministic UTF-8 encoding. |
| Non-idiomatic None Comparison & Redundant Branching | Quality (Flake8 E711, Pylint C0121, R1703, R1705) | 32-37 | `theater_seats.get(seat_id) == None` uses equality instead of identity comparison `is None`. Furthermore, lines 34–37 use a redundant `if not ...: return True else: return False` construct. | Change comparison to `theater_seats.get(seat_id) is None`, and simplify the boolean return directly to `return not theater_seats[seat_id]["is_sold"]`. |
| Unused Imports and Local Variables | Quality / Cleanliness (Flake8 F401, F841; Pylint W0611, W0612) | 6, 31, 41, 63 | The module imports `math` without using it. It also assigns `booking_fee = 1.50` and loops over `seat` in `theater_seats.items()` without using those variables, adding dead code. | Remove unused `import math`, eliminate `booking_fee`, and iterate directly over `theater_seats.values()` instead of unpacking unused key variables. |
| Non-compliant Naming, Missing Docstrings, and Style Violations | Style / PEP 8 (Pylint C0103, C0116, C0304; Flake8 E501, W292) | 15, 19, 82 | `reserveSeat` violates PEP 8 snake_case naming. Functions lack docstrings, line 19 exceeds 79 characters, and the file lacks a trailing newline at EOF. | Rename `reserveSeat` to `reserve_seat` (providing backward-compatible alias if needed), add PEP 257 docstrings to all functions, wrap lines to under 79 characters, and ensure trailing newline. |
| Hardcoded Sensitive Secret / Key | Security (Manual Inspection / Bandit B105) | 70 | `box_office_key = "BOX_OFFICE_SECRET_PASS_2026"` hardcodes administrative credentials into the source code, creating credential exposure risks in source control. | Load administrative secrets from environment variables (e.g., `os.environ.get("BOX_OFFICE_KEY", ...)`). |
